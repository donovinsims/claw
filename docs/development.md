# Development Guide

This guide describes how to run Claw locally with Convex and the optional OpenClaw bridge.

## Prerequisites

- Node.js 20+
- npm 10+
- Convex CLI access (`npx convex dev`)
- Optional for tunnel workflows: `cloudflared`

## Install

```bash
npm install
```

## Environment

Create `.env.local` in repo root:

```bash
NEXT_PUBLIC_CONVEX_URL=https://YOUR_DEPLOYMENT.convex.cloud
NEXT_PUBLIC_CONVEX_SITE_URL=https://YOUR_DEPLOYMENT.convex.site
```

For bridge process, pass `CONVEX_SITE_URL` at runtime:

```bash
CONVEX_SITE_URL=https://YOUR_DEPLOYMENT.convex.site npm run bridge
```

## Run Full Local Stack

Use 2-3 terminals:

1. Convex backend

```bash
npx convex dev
```

2. Dashboard app

```bash
npm run dev
```

3. Optional ingest bridge

```bash
CONVEX_SITE_URL=https://YOUR_DEPLOYMENT.convex.site npm run bridge
```

## Scripts

Root scripts (`package.json`):

| Command | What it does |
|---|---|
| `npm run dev` | Starts Next.js dev server (Turbopack) |
| `npm run build` | Production build |
| `npm run start` | Starts built app |
| `npm run lint` | Runs ESLint |
| `npm run bridge` | Runs bridge watcher in `bridge/` |

Bridge package scripts (`bridge/package.json`):

| Command | What it does |
|---|---|
| `npm run start` | Runs bridge once with `tsx index.ts` |
| `npm run dev` | Runs bridge in watch mode |

## Code Generation

Convex generated files are in:

- `convex/_generated/api.d.ts`
- `convex/_generated/dataModel.d.ts`
- `convex/_generated/server.d.ts`

Regenerated by Convex CLI as schema/functions evolve.

## Quality Checks

Run before opening a PR:

```bash
npm run lint
npx tsc --noEmit
```

Note:
- `next.config.ts` currently allows production builds to ignore TypeScript and ESLint errors.
- Keep local quality checks strict even though build is permissive.

## UI Implementation Notes

- Mobile breakpoint logic is in `src/hooks/use-mobile.ts`.
- Mission queue drag-and-drop is powered by `@dnd-kit`.
- Theme tokens and motion/accessibility behavior are in `src/app/globals.css`.
- Convex client setup is in `src/components/convex-client-provider.tsx`.

## Common Local Issues

### Dashboard shows no data

- Check `NEXT_PUBLIC_CONVEX_URL` is valid.
- Confirm Convex dev deployment is running.

### Bridge exits with fatal message

- Ensure `CONVEX_SITE_URL` is provided and points to `*.convex.site`.

### Activity feed stays empty

- Verify OpenClaw transcript files exist under `~/.openclaw/agents/*/sessions/*.jsonl`.
- Confirm bridge process is running and can reach Convex endpoint.
